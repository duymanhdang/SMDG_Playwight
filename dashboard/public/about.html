SimpleMDG Automation Hub

Loading version…

An internal QA orchestration dashboard for the SimpleMDG Playwright test suites. It launches Playwright runs (specs or whole suites), tracks live and historical results, classifies failures, tracks flaky-test quarantine, groups runs into regression cycles, and exposes coverage/insights views — all backed by local SQLite storage, no external services required beyond an optional AI-diagnosis integration and an optional webhook notifier.

New here? Walk through the Setup Wizard to check Playwright/suite discovery, opt in to the Hub Reporter, and start tagging tests for business-process coverage.
